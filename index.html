형태보다 가변성. 행사마다 극장식·테이블·그룹·센터 무대로 바꿔 쓸 수 있는 평바닥·이동식 구성을 원하고, 계단식 고정석에는 부정적입니다.

도면보다 운영 현실성. 가구 보관, 전환 인력·시간, 무대 이동 시 전원·AV, 단순한 장비 조작까지 함께 설계되길 요청했습니다.

연사 동선과 행사 전후 공간. 대기실에서 무대로 객석을 거치지 않는 동선, 홀과 구분되는 리셉션·전시·상담 공간이 공통 요구입니다.

  • 설계방켓 241석은 계단석을 포함한 수량 — 계단식 좌석과 원형 테이블을 동시에 쓸 상황이 있는지 검토 필요.
  • 설계"벽을 없앤다"의 범위 확인 필요 — 막힌 세미나실이 아니면 시선이 바깥으로 열리는데, 행사 성격에 따라 장점일 수도 단점일 수도 있음.
  • 설계조정실이 시야를 가리지 않으려면 좌석 레벨이 최소 2m 이상 높아야 하고, 출입문 구조를 고려하면 시야각이 불리함.
  • 설계곡면 LED는 좌우 끝자리에서 화면 선명도가 떨어질 수 있음.
  • 설계기존 대비 무대·스크린 규모가 작음.
  • 설계연사가 객석을 거쳐 무대로 가야 함 — 거리는 길지 않으나 공연성 행사에서는 문제 가능. 창고·대기실 쪽(동측·북측)으로 백스테이지 동선을 확보하고 소음을 차단하는 구조 필요.

  4. 운영 설계를 도면과 함께 제출하도록 협의 시 요청 예정: 가구 보관 창고 면적, 배치 전환 시나리오(인력·시간), 바닥 가이드, 무대 이동 시 전원·AV, 촬영 조건.
  5. VIP 상담룸은 2~4인·4~6인 각 1실 기준 위치안을 협의 시 요청 예정(가변 미팅룸으로 확장 가능하게).
